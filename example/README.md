# Example material

Everything in this folder is generated by temporal-system itself. The main
example is the most complex fixture of the paclet's Csound test suite
(`tests/test_csound.nb`, Test 7): sixteen `sine_osc` notes and eight
`click` hits, four accent triggers, six curves whose p-field bindings
compose (`p5 * amplitude * ampScale`; `p6` replaced by
`panSweep * panDepth`), labeled section markers, and a
4/4 → 5/8 → 7/8 → 3/4 meter grid at 96 BPM.

| File | Content |
|---|---|
| `timeline_example.nb` | Notebook that builds the fixture, draws/exports the timeline (Fig. 2), and produces every file below |
| `timeline_example.csd` | Aggregated Csound rendering: k-rate curve signals, generated bound copies of both instruments, marker comments, real trigger events |
| `timeline_example.wav` | Audio, compiled by the paclet via `csoundCompileOnExport` |
| `timeline_example_click.csd` | Eighth-note click track of the same timeline across the meter changes |
| `timeline_example_click.wav` | Audio of that click track |
| `paper_note.csd` | One-note rendering whose i-statement is quoted in Sect. 4 of the paper |
| `paper_click.csd` | Minimal 4/4 click whose score is quoted in Sect. 5 of the paper |

Headless regeneration (also rewrites `../figures/timeline_export.pdf|png`):

```bash
wolframscript -file ../tools/make_example.wls
```

Requires a local checkout of `temporal-system` (path set at the top of the
script/notebook) and a Csound binary for the audio steps.
