# Example material

Everything in this folder is generated by temporal-system itself, through
the aggregated Csound renderer (`renderCSnd`).

| File | Content |
|---|---|
| `timeline_example.nb` | Notebook that builds the stemData of Fig. 2, draws/exports the timeline, and produces every file below |
| `timeline_example.csd` | Csound rendering of the same stemData (harmonics 2–9 of A2 on `sine_osc`); the amplitude curve becomes a k-rate control signal bound to p5 inside a generated bound copy of the instrument, the markers become score comments |
| `timeline_example.wav` | Audio, compiled by the paclet via `csoundCompileOnExport` |
| `click_track.csd` | Click track quoted in Sect. 5 of the paper (two 4/4 bars at 120 BPM) |
| `click_track.wav` | Audio of the click track |
| `notes.csd` | One-note rendering whose i-statement is quoted in Sect. 4 |

Headless regeneration (also rewrites `../figures/timeline_export.pdf|png`):

```bash
wolframscript -file ../tools/make_example.wls
```

Requires a local checkout of `temporal-system` (path set at the top of the
script/notebook) and a Csound binary for the audio steps.
